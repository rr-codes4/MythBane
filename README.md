# MythBane
It is an AI-powered dashboard applcation designed to debunk myth/conspiracy theories/stereotypes.Using AI-agent,that uses verified data.

#Features
* I have used OpenAI-4o-mini model using OpenAI's API from ai.hackclub.com
*I have provided it tools that include Wikipedia,DuckDuckGO search.
*It provide structured verdicts
* The user interface is built using flask.
*I have given it a cyber aesthetic
